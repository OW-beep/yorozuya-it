## 一言でいうと「作業机」と「本棚」

パソコンやスマホのスペック表には、「メモリ 8GB」「ストレージ 256GB」のように、似た単位の数字が並んでいます。どちらも「容量」ですが、役割はまったく違います。

- **メモリ(RAM)**:今まさに使っているアプリやデータを広げておく場所。**作業机**にあたる
- **ストレージ**:写真・文書・アプリ本体などを保存しておく場所。**本棚**にあたる

本棚(ストレージ)から必要な本を取り出して、机(メモリ)の上に広げて作業する、と考えると分かりやすくなります。机が広いほど、たくさんの資料を同時に広げて作業できます。一方、本棚が大きいほど、たくさんの本をしまっておけます。

## 2つの違いを表で比べる

| | メモリ(RAM) | ストレージ |
|---|---|---|
| 役割 | 作業中のデータを一時的に置く | データを長期間保存する |
| 電源を切ると | 中身が消える | 中身が残る |
| 速度 | とても速い | メモリより遅い |
| 容量の目安 | 数GB〜数十GB | 数百GB〜数TB |
| 不足すると | 動作が重くなる・固まる | 保存や更新ができなくなる |

## 「重い」のはメモリ?ストレージ?

### メモリが足りない時の症状

- アプリを複数開くと、急に動作が遅くなる
- ブラウザのタブをたくさん開くと、画面の切り替えがもたつく
- アプリが突然終了する

机がいっぱいで、新しい資料を広げる場所がない状態です。使っていないアプリやタブを閉じるだけで、改善することがあります。

### ストレージが足りない時の症状

- 写真や動画を保存しようとすると、「容量がいっぱいです」と表示される
- OSやアプリの更新ができない
- パソコンやスマホ全体の動きが、徐々に鈍くなる

本棚がいっぱいで、新しい本をしまえない状態です。不要なファイルの整理や、クラウドへの退避が対策になります。スマホの場合は[スマホのストレージを空ける方法](/posts/sumaho-storage)も参考になります。

## 確認する方法

### Windowsの場合

1. キーボードの「Ctrl」「Shift」「Esc」を同時に押して、タスクマネージャーを開く
2. 「パフォーマンス」タブを開く
3. 「メモリ」で、使用中の量と全体の容量を確認する

ストレージの空き容量は、エクスプローラーの「PC」(または「このPC」)で、ドライブごとの空きを確認できます。

### スマホの場合

スマホの「設定」アプリの、ストレージに関する項目で、使用済み・空きの容量を確認できます。スペック表の「RAM」はメモリのことで、こちらは設定画面からは変更できません。

## 買い替え・増設で迷った時の考え方

- **保存したいものが増えた(写真・動画など)** → ストレージを増やす、またはクラウドを活用する
- **同時にたくさんのアプリを開くと重い** → メモリを増やす、または使うアプリを絞る
- **電源を入れてから使えるまでが遅い** → ストレージの種類(SSDかHDDか)が影響していることがある。違いは[SSDとHDDの違い](/posts/ssd-hdd-chigai)で解説しています

パソコンが重い原因をもっと広く切り分けたい場合は、[パソコンが重い時の対処法](/posts/pc-omoi)もあわせてご覧ください。

## よくある勘違い

- 「メモリを増やせば保存容量も増える」 → 増えません。保存容量はストレージで決まります
- 「ストレージが空いていれば、動作も軽いはず」 → メモリ不足で重くなることもあります
- 「メモリのデータは、保存されている」 → 電源を切ると消えるため、保存操作が必要です

## 振り返ると

メモリは今使うデータを置く作業机、ストレージは保存しておく本棚です。「重い」と感じた時は作業机の広さ、「保存できない」と感じた時は本棚の広さを見る、と切り分けると、原因が見つけやすくなります。
