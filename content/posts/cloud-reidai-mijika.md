## クラウドは、すでに毎日使っている

「クラウドは、難しそう」と感じている方も、**すでに毎日、クラウドを使っています**。写真を見る、メールを読む、動画を観る。こうした場面の多くで、クラウドが動いているのです。

クラウドの意味は、[クラウドはどこにある?実体は「誰かの会社のコンピューター」](/posts/cloud-toha)で、仕組みは、[クラウドの仕組みを図解でやさしく](/posts/cloud-shikumi-zukai)で解説しています。この記事では、**身近な例**で、イメージをつかみます。

## 身近なクラウドサービスの例10選

| 場面 | 例 | クラウド側にあるもの |
|---|---|---|
| 写真・動画の保存 | Googleフォト、iCloud写真 | 写真・動画のコピー |
| メール | Gmail | メール本体 |
| 文書・表計算 | Googleドキュメント、Microsoft 365 | 文書データ、共同編集の状態 |
| ファイルの保管・共有 | Dropbox、Googleドライブ | ファイルのコピー |
| 動画配信 | Netflix、YouTube | 動画ファイル |
| 音楽配信 | Spotifyなどの音楽サービス | 音楽データ、プレイリスト |
| ビデオ会議 | Zoomなど | 会議の通信を中継するコンピューター |
| 地図・乗換案内 | 地図アプリ | 地図データ、経路の計算 |
| チャット・SNS | LINE、SNS | メッセージ、投稿、画像 |
| スマホのバックアップ | iCloudバックアップ、Googleのバックアップ | 端末の設定やデータのコピー |

どれも、**データや処理が、インターネットの向こう側(データセンター)**にあり、手元の端末は、それを表示したり、操作したりしています。

## 気づかずに使っているクラウド

「クラウドを使っている」という意識がなくても、実際には使っているものがあります。

- **スマホの連絡先**が、機種変更しても、新しい端末に移る(クラウドに同期されている)
- **写真**が、スマホとパソコンの両方で、見られる
- **スマホの自動バックアップ**(設定をオンにしている場合)
- **銀行・ポイントのアプリ**の、利用履歴の表示
- **スマートスピーカーや、家電のアプリ**の連携

「クラウド」という言葉を、見かけなくても、**複数の端末で、同じ内容が見られる**なら、クラウドで同期されている可能性が高いです。

## クラウドの、便利な点

- **どの端末からも、同じデータが見られる**:スマホ、パソコン、タブレットで、続きから使える
- **端末が壊れても、データが残る**:クラウドにコピーがあれば、復元できる
- **自分で機器を、管理しなくてよい**:サービスの運営側が、設備を管理している
- **共有・共同作業が、しやすい**:複数人で、同じ文書を同時に編集できる

## こんな時は、こんなクラウド

目的別に、向いているクラウドの種類を、整理しました。

| やりたいこと | 向いているクラウドの種類 |
|---|---|
| 写真や動画を、保存・共有したい | 写真向けのクラウドストレージ |
| 文書を、複数人で同時に編集したい | クラウド型の文書作成サービス |
| 大きなファイルを、人に渡したい | ファイルの共有サービス |
| スマホの故障に、備えたい | スマホのバックアップ機能(iCloud・Googleなど) |
| 遠く離れた人と、会議をしたい | ビデオ会議サービス |

「どのサービスがよいか」で迷ったら、まず**「何をしたいか」**を決めてください。目的が決まれば、選ぶべき種類が、自然に絞られます。

## 使う前に、確認したいこと

便利な反面、次の点を確認しておくと、困りごとを避けられます。

1. **二段階認証をオンにしているか**:アカウントが乗っ取られると、預けたデータにも不正にアクセスされます([二段階認証はSMS・認証アプリ・パスキーのどれがいい?](/posts/nidan-ninsho-sms-app-passkey-hikaku))
2. **容量の上限を把握しているか**:無料プランの上限に達すると、新しいデータが保存されなくなります
3. **共有リンクの公開範囲は適切か**:「リンクを知っている全員が見られる」設定のまま、放置していないか
4. **やめる時に、データを取り出せるか**

特に、**「クラウドに保存している=バックアップ済み」とは限らない**点には、注意が必要です。同期の仕組みでは、**消した操作も反映される**ことがあります([同期とバックアップの違い](/posts/douki-backup-chigai))。

## クラウドサービスを、選ぶ時の視点

容量やプランの比較は、[クラウドストレージの比較](/posts/cloud-storage-hikaku)が参考になります。選ぶ時は、**価格だけで決めず**、次の点も見てください。

- 自分が使う**端末**(iPhone、Android、パソコン)に、合っているか
- **容量の目安**と、**将来の増やしやすさ**
- **セキュリティの機能**(二段階認証、共有の管理)
- **解約や、データの取り出し**のしやすさ

## まとめ

- クラウドは、**写真・メール・文書・動画・音楽・ビデオ会議**など、身近なサービスの多くで使われている
- **自動バックアップや、連絡先・写真の同期**など、気づかずに使っているクラウドも多い
- 便利な点は、**どの端末からも使える**、**端末が壊れてもデータが残る**
- 使う前に、**二段階認証・容量・共有範囲・解約とデータ取り出し**を確認する
- **同期は、バックアップとは別**。大切なデータは、2か所以上に
