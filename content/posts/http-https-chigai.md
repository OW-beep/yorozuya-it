## 違いは「通信が守られているか」

Webサイトのアドレスは、「http://」または「https://」で始まります。この「S」は「Secure(安全な)」の頭文字で、**通信が暗号化されている**ことを表します。

HTTP(Hypertext Transfer Protocol)は、ブラウザとサーバーが、Webページのデータをやり取りするための決まりごとです。このやり取りを、**暗号化の仕組み(TLS)で保護**したものが、HTTPSです。仕組みの詳細は、[SSL/TLSとは](/posts/ssl-tls-toha)で解説しています。

## 比較表

| 項目 | HTTP | HTTPS |
|---|---|---|
| 通信の暗号化 | されない | される |
| 盗み見の防止 | できない | 通信内容を、第三者から読まれにくい |
| 改ざんの検知 | できない | できる |
| サーバーの身元確認 | できない | 証明書で、ドメインの確認ができる |
| 標準のポート番号 | 80番 | 443番 |
| ブラウザの表示 | 「保護されていない通信」と出ることがある | 鍵マークが表示されることが多い |

ポート番号の意味は、[ポート番号とは](/posts/port-bango-toha)で解説しています。

## HTTPのままだと、何が危ないのか

暗号化されていない通信は、途中の経路(公共のWi-Fiなど)で、**内容を盗み見られたり、書き換えられたりする**可能性があります。

- ログインのIDとパスワードが、見られてしまう
- 入力した個人情報が、盗まれる
- ページに、不正な内容が、差し込まれる

特に、カフェや駅の、公共Wi-Fiを使う時は、注意が必要です。

## 鍵マークの意味と、限界

ブラウザのアドレスバーには、HTTPSの接続では、鍵のようなマークが表示されることがあります。このマークが示すのは、**「通信が暗号化されている」**ということだけです。

### 「HTTPSなら安全」ではない

悪意のある人でも、自分のサイトに、HTTPSを設定することができます。そのため、フィッシングサイト(偽サイト)でも、HTTPSで、鍵マークが付いていることがあります。

次の点を、あわせて確認しましょう。

- **アドレス(ドメイン)の綴り**:本物とよく似た、偽のドメインではないか
- **メールやSMSのリンクから来ていないか**:公式のアプリやブックマークから開く
- **入力を求められる内容が、不自然ではないか**

フィッシングの手口は、[フィッシングとは](/posts/phishing-toha)で詳しく解説しています。

## サイト運営者にとっての、HTTPS

自分でサイトを運営する場合、HTTPSは、ほぼ必須です。

- 閲覧者の通信を、保護できる
- ブラウザが、「保護されていない通信」と警告するのを避けられる
- 検索エンジンも、HTTPSを推奨している

Vercelなどのサービスでは、HTTPSが標準で有効になるため、特別な設定は、不要なことが一般的です。

## 振り返ると

HTTPSは、HTTPの通信を暗号化して、盗み見や改ざんを防ぐ仕組みです。ただし、HTTPSは通信の保護であり、サイトの信頼性の保証ではありません。ログインや決済の前には、アドレスの綴りと、アクセス元の確認も忘れずに行いましょう。
