## まずはこの6つ:基本の編集操作

| 操作 | Windows | Mac |
|---|---|---|
| コピー | Ctrl+C | ⌘+C |
| 切り取り | Ctrl+X | ⌘+X |
| 貼り付け | Ctrl+V | ⌘+V |
| 元に戻す | Ctrl+Z | ⌘+Z |
| すべて選択 | Ctrl+A | ⌘+A |
| 保存 | Ctrl+S | ⌘+S |

この6つだけでも、マウスで右クリックメニューを開く回数が、大きく減ります。

## 画面・ウィンドウを操作する

| 操作 | Windows | Mac |
|---|---|---|
| アプリを切り替える | Alt+Tab | ⌘+Tab |
| デスクトップを表示する | Windowsキー+D | F11(設定による) |
| 画面をロックする | Windowsキー+L | Control+⌘+Q |
| エクスプローラーを開く | Windowsキー+E | Finderを開く(⌘+Option+Space など) |
| タスクマネージャーを開く | Ctrl+Shift+Esc | ⌘+Option+Esc(強制終了) |

離席する時は、**Windowsキー+L**で、画面をすぐにロックできます。セキュリティ上も、習慣にしておくと安心です。パソコンが固まった時に、タスクマネージャーを開く方法は、[パソコンが固まった時の対処法](/posts/pc-freeze)でも使います。

## 検索・ブラウザで便利なもの

| 操作 | Windows | Mac |
|---|---|---|
| ページ内を検索する | Ctrl+F | ⌘+F |
| 閉じたタブを、再び開く | Ctrl+Shift+T | ⌘+Shift+T |
| 新しいタブを開く | Ctrl+T | ⌘+T |
| ファイル名を変更する | F2 | Return(Finderで選択中) |

「Ctrl+Shift+T」は、誤って閉じたタブを復活できる、知っておくと得をするショートカットです。

## Windowsならではの便利機能

- **Windowsキー+Shift+S**:画面の好きな範囲を切り取って、スクリーンショットを撮る。詳しくは[スクリーンショットの撮り方](/posts/screenshot-torikata)で解説しています
- **Windowsキー+V**:クリップボードの履歴を表示し、過去にコピーしたものを選んで貼り付けられる(機能を有効にする必要がある場合があります)

## 覚え方のコツ

1. **毎日やる操作を、1つ決める**:たとえば「コピー・貼り付け」から始める
2. **マウスに手が伸びたら、ショートカットがないか考える**:その場で調べて、1回使ってみる
3. **付箋に、3つだけ書いて貼る**:増やしすぎず、定着してから、次を追加する

アプリごとのショートカットは、ExcelやChromeなど、各アプリの公式ヘルプにまとまっています。

## 振り返ると

ショートカットキーは、毎日の作業を、少しずつ速くしてくれます。すべてを覚えるのではなく、「コピー・貼り付け・元に戻す」など、よく使うものから1つずつ増やしていきましょう。
